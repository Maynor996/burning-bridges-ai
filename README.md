## 怎么用

1. 打开 [burningbridgesvideoai.com](https://burningbridgesvideoai.com)
2. 上传 Photo 1（主角）；可选 Photo 2（包间朋友）
3. 勾选授权 → 选画幅 / 分辨率 → Create
4. Stripe 一次性积分包：Single **$8.88** / 3-pack **$16.99** / 10-pack **$39.90**（付费成片约 **15 秒**）
